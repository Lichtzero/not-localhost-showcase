# The Class Project Library
### Srishti Manipal Institute of Art, Design & Technology (MAHE)

An interactive, motion-driven digital library and experimental bookshop showcasing the design inquiries, tactile artifacts, and speculative interfaces of 15 students.

Built with **Next.js (App Router)**, **React**, **TypeScript**, **Tailwind CSS**, and **CSS 3D Transforms**.

---

## 📖 Features

* **Authentic Institutional Branding**: Preserves the official Srishti Manipal Institute and MAHE identity from the supplied university logo assets.
* **Tactile 3D CSS Books**: Realistic physical book anatomy with front covers, visible spines, layered page thickness, paper banding, dynamic contact shadows, and cursor-responsive perspective tilt.
* **15 Art-Directed Covers**: Diverse editorial styles ranging from Swiss grid typography and brutalist terminal aesthetics to biological generative glyphs and origami paper folds.
* **Dual-Spread Folio Reader**: Clicking any book opens a detailed editorial view with briefs, personal philosophies, process milestones, experimental media, and reflections.
* **Central Data Architecture**: Fully data-driven from `data/students.ts`, allowing easy updates without modifying UI code.
* **Contributor Directory**: Searchable class directory linking directly to each student's book.
* **Accessible & Responsive**: Keyboard navigable (Tab, Enter, Arrow keys, Esc), responsive shelf compositions, and reduced-motion compliant.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for production
```bash
npm run build
```
