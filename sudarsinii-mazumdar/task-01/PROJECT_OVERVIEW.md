# The Bangalore Pub Trail '26 &mdash; Project Overview

> **A 15-Member Group Showcase Mapped Across Bengaluru's Legendary Drinking Spots**

---

## 1. Briefly Explain the Idea

### Core Concept
Instead of presenting a conventional, static portfolio or a plain grid of resumes, **The Bangalore Pub Trail** reimagines our group’s 15 software projects as **stops on an illustrated adventure expedition across Bengaluru's most iconic pubs, microbreweries, and resto-bars**.

### The Metaphor: Pubs, Engineers & Craft Brews
- **15 Iconic Bangalore Landmarks:** From legacy rock hubs like *Pecos* and rooftop student spots like *Chin Lung*, to craft microbreweries like *Toit*, *Byg Brewski*, and *Bob's Bar*, each physical pub serves as the creative "home" for one student engineer.
- **The Resident Engineer:** Each group member is featured at their assigned bar as the creator and resident engineer.
- **The Signature Brew & Bite:** Each project is paired with a metaphorical drink recipe and authentic local bar bite that reflects its software architecture (e.g., an ultra-low-latency Voice AI paired with a *Mysore Filter Coffee Stout*, or a high-throughput Rust message broker paired with *Spicy Peri-Peri Wings*).
- **Bar Tab Receipt:** Key engineering metrics—such as Git commits, lines of code, test coverage, and benchmark latencies—are cleverly presented as an authentic itemized Bangalore bar tab invoice.

### Visual Aesthetic
Inspired by **hand-drawn outdoor expedition and hiking maps**, the interface trades harsh, dark cyberpunk clutter for **warm ivory cream tones (`#faf5e8`), gentle sky-blue winding lakes, rolling sage-green hills, pine trees, and a dotted trail path**. It creates a peaceful, approachable, and memorable showcase that stands out from typical AI-generated landing pages.

---

## 2. What a Visitor Can Do

Visitors landing on the web application can interact with the showcase in the following ways:

### 🚶 1. Explore the Map as an Animated Hiker
- **Free Roam Walking:** Navigate the illustrated trail freely using keyboard controls (<kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> or <kbd>&uarr;</kbd><kbd>&larr;</kbd><kbd>&darr;</kbd><kbd>&rarr;</kbd>), on-screen directional buttons, or by simply clicking anywhere on the map to walk there.
- **Guided Trail Progression:** Use the bottom control bar's **"NEXT STOP ➔"** and **"PREV STOP"** buttons to smoothly travel in sequence along the dotted trail from Stop #1 through Stop #15.

### 🏠 2. Step Inside Any Pub to Inspect Group Projects
- **Proximity & Click Triggers:** When walking near a pub or clicking on its cottage marker, a visit prompt invites the user inside.
- **Comprehensive Project Breakdown:** Inside the clean modal window, visitors can read:
  - The project title, problem statement, and architectural summary.
  - Interactive **Tech Stack Ingredients** (e.g., PyTorch, Rust, Next.js, WebAssembly, WebGPU).
  - **Key Highlights** detailing real technical achievements and latency benchmarks.
- **Live Demo & Source Code:** Direct action links allow visitors to open the **Live Hosted Application** or explore the **GitHub Repository**.

### 👤 3. Learn About Each Group Member
- View the developer’s avatar, engineering role, philosophy quote, and recommended local bar bite.
- Connect directly with each student via their **GitHub**, **LinkedIn**, and personal **Portfolio** links.

### 📜 4. Collect Passport Stamps (Gamified Exploration)
- Every visited pub features an interactive **"STAMP PASSPORT"** action.
- The top navigation tracks progress in real time (e.g., `4 / 15 STAMPED`).
- Visitors can open their digital **Expedition Passport booklet** to see which pubs have been verified and export a text certificate once all 15 stops are explored.

### 🍺 5. Pour the Signature Brew & Inspect the Bar Tab
- Click **"POUR SIGNATURE BREW"** to trigger an animated pouring sequence with sound effects.
- View the project's **Bar Tab Receipt** detailing commits, lines of code, test coverage, and caffeine spent during development.

### 🔍 6. Filter by Neighborhood or Technology Stack
- **Area Filters:** Filter stops by Bengaluru zone (*Indiranagar, Koramangala, Central / Church Street, Lavelle Road, Hennur / North*).
- **Tech Filters:** Filter by domain (*AI & Vision, Fullstack & Web, Systems & Cloud, Security & Web3*).
- **View Toggle:** Seamlessly switch between the **Illustrated Trail Map View** and a clean **All 15 Pubs Directory Grid View**.

### ✏️ 7. In-Browser Customization (Edit Member Details)
- Visitors and team evaluators can click **"Edit Member"** on any stop to update names, project titles, tech stacks, or URLs in real time.
