01 / Brief

15 people, one site, one stranger

Can a person who knows nothing about this class explain the site back to me after looking at it for ten seconds?

That was the test I set for myself. The class has 15 people and each has a project. This is a UI/UX project, so it has to look good and feel interactive too. I wrote the brief down as a checklist and checked it at the end.

02 / Idea

A café is a place where things develop

The module is called Incubation Café, so I used the name as the theme. A café and an incubator have one thing in common: you leave something to develop. So every project on the site shows how far along it is, using coffee words.

Think of it as a status field with 4 values:

Grounds

Just started. The problem is picked, no direction yet.

Brewing

Trying out ideas. Nothing is locked in.

Steeping

One idea is chosen and is being tested and fixed.

Poured

Has a working prototype. Ready to show.

Each project also has a type. I assigned these as placeholders:

ProductServiceResearchInteractionSystems

The look comes from the same idea. Green is the culture growing in a jar, brown is coffee. Each card has a small blob drawn from a fixed seed, so a card always looks the same and no image files are needed.

03 / Visitor

What you can do on it

index.html
  1. 1Filter by typeShows only that type of project. The others hide.
  2. 2Hover a pillA small popup says what the word means. On a phone you tap it. I first made a separate glossary section, then removed it. You had to scroll away from the card to read it.
  3. 3Cards tiltThe card leans toward the cursor. Only on devices with a mouse, and switched off if the system has reduced motion on.
  4. 4Click a cardOpens a bigger view. Esc or a click outside closes it.
04 / Testing

Three things that were broken

Before this round I had only checked that the code had no syntax errors. That does not tell you if the page works. So I opened it in a browser at 1280, 768 and 390 px and clicked through everything. It found three bugs. Drag the sliders to compare.

Bug 1 / serious

All 15 cards disappear

Symptom
Half a second after load the grid is empty.
Cause
Cards start at opacity 0 and the animation fades them in. I added a line that removes the animation when it ends, so the cards went back to their start state, which is invisible. I added it for the card tilt and never looked at the result.
Fix
Cards now animate from hidden and rest visible. The line is gone.

Bug 2 / medium

Nav breaks on a phone

Symptom
The "MDes · Yr 2" tag wraps onto 3 lines and the site name wraps too.
Cause
Not enough width and no rule to stop the text from wrapping.
Fix
Below 640 px the tag and the About link are hidden. The site name never wraps.

The lamp hangs from nothing

Symptom
The lamp wire starts in mid-air under the nav bar.
Cause
The wire started at the top of the 3D scene box, not at the top of the page.
Fix

06 / Choices

Why I did it this way

Popups, not a glossary

The meaning should be where you are looking. A separate section means scrolling away from the card and back.

CSS for the 3D

No 3D library, so no extra download and the whole site stays one file. I kept it to one corner so the text stays easy to read.

Placeholders that look real

"Person A" with lorem ipsum would hide layout problems. Realistic one-liners show how long text behaves in the cards.

07 / Next

What I have not checked

  • User test. Show it to 3 to 5 classmates for ten seconds and ask them to explain it. This is the test from the brief and I have not done it yet.
  • Other browsers. I only tested in Chromium. Safari and Firefox are not checked.
  • Fonts. The fonts load from Google Fonts and my test browser could not reach them, so the screenshots use fallback fonts.
  • Keyboard use. Focus and Enter/Space are in the code but I only tested with a mouse.
  • Real content. Replace Person A to O with real names, projects, stages and images.

Built step by step with Claude, an AI assistant, and checked by running the page in headless Chromium. Screenshots on this page are from those test runs.
